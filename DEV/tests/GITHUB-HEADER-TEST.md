## Working rule

**Family mark**  
POST-APOLLO // or META APOLLO LOGOS //

**Project mark + project name**  
The dominant identity.

**Short descriptor**  
One short line explaining what kind of thing this is.

**State strip**  
Lives outside permanent artwork because it changes.

Examples:

`ACTIVE · c<STATE>`

`EXPERIMENTAL · c<STATE>`

`STABLE · c<STATE>`

---

## Family distinction

Use **POST-APOLLO //** for repos that are primarily part of the Post-Apollo software/system family.

Use **META APOLLO LOGOS //** for repos that are primarily part of the larger philosophical, historical, cognitive, or design-language body.

A project can still belong to the larger Meta Apollo ecosystem without putting META APOLLO LOGOS on its banner.
