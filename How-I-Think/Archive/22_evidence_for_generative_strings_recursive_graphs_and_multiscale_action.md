# 23. Failure Test: Local Skill Must Survive Wide Modeling

If the model is right about high zoom range, then:

> broad strategic attention should not always destroy local execution.

We should continue looking for:

- moments where local mechanics remain strong under high global complexity
- moments where they collapse

Both matter.

If local detail consistently disappears under wide FOV, the “deeply resolved graph-of-graphs” claim needs reduction.

---

# 24. Failure Test: Weird Plans Must Produce Value Sometimes

A dangerous failure mode is:

> every bizarre route is reinterpreted as deep strategy.

That is unacceptable.

The model requires outcome checks.

Ask:

- did the objective fall?
- did enemy attention produce value?
- was resource exchange favorable?
- did the plan depend on impossible coordination?
- would a simpler route have been better?
- did the user actually predict the payoff before the result?

Without this, “graph thinking” can become an excuse generator.

---

# 25. Failure Test: Strings Must Regenerate Structure

A true generative String should do more than summarize.

It should allow:

- relevant branches to return
- action policy to survive
- missing detail to be reconstructed
- later information to attach correctly

If compact lines routinely lose the important structure, then the model is overstated.

- compact action

Costs:
