# 1. Claim Under Test

The core claim from file 18 is:

> **The user operates through a persistent graph with serial output, graph-scheduled attention, cheap return pointers, and external spatial-semantic workspaces.**

This is stronger than:

> “the user thinks nonlinearly.”

The evidence needs to show:

- multiple active branches
- return after suspension
- serial action without serial processing order
- spatial / visual pointers
- external environment participating in retrieval
- movement through the environment during thought

---

# 2. Live Chat Evidence: Non-Chronological Consumption

The user explicitly reported that he does not consume the conversation in strict order.

He may:

> listen to one response  
> → send a response  
> → return to an earlier response  
> → notice a newer response has finished  
> → read that  
> → go back again  
> → later send a message about an older branch.

This behavior was already visible before it was named.

The important evidence is not simply:

> old messages are revisited.

It is:

> **older branches remain live while newer branches are created.**

That is directly consistent with persistent graph state.

---

# 3. Live Chat Evidence: Waiting on AI While Servicing Another Branch

The user described seeing a response still generating and thinking roughly:

> “he’ll finish that soon; I’m going to listen to some other shit.”

Then he returns later.

This is unusually clean evidence for:

> **asynchronous branch scheduling.**

One branch remains pending.

Another branch becomes active.

The user later resumes the pending branch.

This is not inferred from memory.

It was described while actively happening.

---

# 4. Live Chat Evidence: Return Context Includes Provenance

The user reports remembering not only:

> what a message said

but often:

- which message he was waiting for
- which order he sent messages in
- why he sent them
- what earlier correlation triggered a story
- which branch one response belonged to

This suggests:

> branch state contains some provenance.

The model does not require perfect memory.

It requires enough return metadata to resume useful context.

---

# 5. Tiny Pointer Evidence

The user identified small marks as return pointers.

Examples:

- gap
- slash
- dot
- picture

The key observation:

> the mark itself may carry almost no explicit semantic payload.

Yet it can trigger:

> “Oh. That’s where.”

This supports:

> **pointer memory cheaper than payload memory.**

Alternative explanations include:

- ordinary bookmarking
- visual memory
- spatial memory

Those are compatible with the functional model.

The important point is the repeated use of minimal cues to reopen larger contexts.

# 22. Prediction: Rearrangement Should Sometimes Increase Reorientation Cost

If space is semantic, then arbitrary rearrangement should sometimes produce:

- “where the fuck is it?”
- slower context reload
- extra searching
- feeling of wrongness
- accidental branch loss

This should happen most strongly for:

> highly indexed objects

and less strongly for:

> generic clutter.

That distinction can help separate semantic topology from mere habit.

The important thing is not:

> every example fits.

> **the model was already predicting kinds of behavior that later became visible in chat, room layout, tool placement, paper research, and old artifact retrieval.**

- misses
