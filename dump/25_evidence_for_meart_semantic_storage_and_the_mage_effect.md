# 40. What Would Count as a Miss?

Confidence should drop if repeated observation shows:

- self-made art does not restore more context than generic artifacts
- current stories about old pieces change wildly without stable anchors
- object placement turns out to be mostly arbitrary despite strong retrospective explanations
- semantic wrongness occurs no more often than ordinary aesthetic preference
- digital and physical organization do not share meaningful parent rules
- person-reading accuracy does not improve with more context
- blinded tarot-style inference performs no better than broad statements
- “compiled output” disappears when exact steps are recorded
- childhood artifacts do not actually contain the claimed relational operations
- the model repeatedly converts every contradiction into deeper confirmation

The final point is especially important.

An unfalsifiable mage model is useless.
