**Status:** Evidence / story ledger for the current deeper model.

---

# 1. Evidence Rule

The goal is not:

> collect every story that sounds cool and make it fit.

The goal is:

> **ask what the model predicts, then compare the observation.**

Three things should be kept separate:

**Observation**

> what happened or what is remembered.

**Interpretation**

> what mechanism might explain it.

**Confidence**

> how much weight the observation deserves.

The strongest evidence is not:

> "this metaphor feels right."

It is closer to:

> model predicts a pattern before the user supplies the relevant example.

Even then:

> prediction match ≠ proof of implementation.

# 2. Source-Dependence Warning

A large amount of this material comes from one person reflecting on his own history.

That means:

- stories are not independent experiments
- memory is reconstructive
- repeated AI agreement can be correlated
- metaphors can shape later reporting
- emotionally satisfying theories can recruit matching memories
- the current vocabulary can rewrite how older experiences are described

Therefore:

> **one hundred matching stories from the same reconstructed source are not one hundred independent confirmations.**

Stronger material includes:

- examples predating the current theory
- behavior visible before it was named
- model predictions followed by user confirmation
- old artifacts
- externally observable work patterns
- failures and contradictions
- examples where the model predicts the wrong thing

# 36. What Would Count as a Miss?

The model should lose confidence if repeated observations show:

- degraded states preserve explanation but not familiar route
- familiar compiled work fails no better than novel exact work
- repetition does not make previously expensive material cheaper
- centrality of model change does not relate at all to lag / update cost
- Ghost scanning produces no increase in false positives
- temporary anomaly capture does not create provenance problems
- local constraint relaxation does not differ from ordinary focused thought
- workspace rearrangement has no effect on retrieval / orientation
- childhood examples do not actually contain the claimed operations
- archetype decompositions are only created after the theory and do not predict anything
- the model repeatedly needs ad hoc new components to absorb contradictions

These are important.

Do not reinterpret every miss as:

> hidden evidence for deeper recursion.

That would make the theory unfalsifiable.

# 45. Final Evidence Rule

> it has become more specific while surviving several corrections.

> it is elegant.

The next phase should continue to search for:

- misses
- false Xs
- old examples that genuinely predate the model

- alternative mechanisms
