Important observations:

- some tokens carry sound associations (`Q` / “cue”)
- some carry images or personal associations
- some have local ordering constraints (`K` should be before `M` but after `j`)
- some produce a strong wrongness signal without a known corrective location (`rhhh`)
- forcing a full serial order tends to collapse back into the standard alphabet or counting
- the nonstandard map is easier to access when individual letters are allowed independent local definitions

This suggests:

> **partial order + weighted graph + overlearned serial chunks**, not a second shuffled alphabet.

# 14. X / Y / Z

Current provisional notation:

**X** — persistent identity handle / thing.

**Y** — time / state-through-time / accumulated transformation axis.

**Z** — currently unexplained dispositional / default component: something treated as intrinsic or ingrained because the current model cannot yet explain it through known experience, biology, context, etc.

Important:

> Z means **currently unexplained**, not “scientifically impossible to explain.”

A relation can therefore be:

```text
X @ Y1
→ transformed
→ X @ Y2
```

while preserving identity.

Likewise, a String can have its own history:

```text
X1 --R1?--> X2 @ Y1
X1 --R2-->  X2 @ Y2
```

This lets the system preserve:

> “I used to think the relationship was R1; now I think it is R2.”

without pretending the old state never existed.
